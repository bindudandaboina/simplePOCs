1.Matrimonial Eligibility System (Console-Based)

Description:
Developed a console-based Matrimonial Eligibility System using Core Java that evaluates a candidate’s suitability based on predefined criteria. The application collects user inputs such as assets, salary, age, height, weight, and sibling status, and uses nested if conditions to validate each parameter step by step.

The system ensures that only candidates meeting all the conditions (financial stability, age range, physical attributes, and personal background) are allowed to proceed to the final stage. If any condition fails, the program terminates with an appropriate message.

Key Features:

Input handling using Scanner class
Logical validation using nested if statements
Step-by-step eligibility checking
User-friendly console interaction

Technologies Used:

Java (Core Java)
OOP Concepts (Encapsulation of logic through structured conditions)

Outcome:
This project helped in understanding control flow, conditional statements, and real-world decision-making logic implementation in Java.

2.Project: Job Eligibility Checker System (Console-Based)

Description:
Developed a console-based Job Eligibility Checker using Core Java that determines whether a candidate is eligible for a top IT job based on a sequence of conditions. The system verifies multiple criteria such as registration status, profile completion, and essential technical skills (Java, SQL, and communication skills).

The application uses nested if statements to evaluate each requirement step by step. If the candidate fails to meet any condition, the system immediately provides feedback on the missing requirement. Only candidates who satisfy all conditions are declared eligible.

Key Features:

Interactive user input using Scanner
Step-by-step validation using nested if conditions
Clear feedback for missing skills or requirements
Real-world simulation of job screening process

Technologies Used:

Java (Core Java)
Control Statements (Nested If)

Outcome:
This project demonstrates understanding of decision-making logic, conditional flow control, and real-time eligibility validation systems in Java.
